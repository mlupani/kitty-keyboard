# Teclado de Gatitos

Juego para aprender las letras y los números jugando con gatitos.

## Cómo jugar

1. **Elegí qué practicar.** En la pantalla de inicio tocá uno de los tres botones: *Todo*, *Letras* o *Números*.
2. **Escuchá y buscá.** El juego dice en voz alta qué tecla apretar (por ejemplo, "Aprieta la letra A") y muestra la letra o el número en grande. Buscala en el teclado de la pantalla, donde además se resalta. Podés tocarla con el dedo o apretarla en tu teclado. Con el botón 🔊 se repite la indicación.
3. **Celebrá.** Si acertás, aparece un gatito con confeti, un elogio y suma una ⭐. Si te equivocás, el juego te dice qué tecla apretaste y te recuerda cuál buscar. Después sale una nueva letra o número. Con el botón 🏠 volvés al inicio.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí <http://localhost:3000> en el navegador.
